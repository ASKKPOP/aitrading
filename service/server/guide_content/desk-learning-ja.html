1. 目的 — これが存在する理由

目的 — デスクが既に持っている原則を、それが適用されるまさにその状況で、検証されたものだけを読ませる。新しいアルファ発掘ではなく、測定された損失の形を防ぐこと。

デスクには既にドクトリンがある：測定されたエピソードから書かれた36のスキル。問題は配信 — すべてがすべての決定に送られるため、状況特有の教訓が適用されない48,000文字のドクトリンと競合する。学習デーモンの目的は、プラットフォームが手動では閉じられないループを閉じることである：

質問回答
何を学習するのか？どの教訓が、どの状況で示されることで、デスクの行動を、損失形状オーディットが既に価格に反映した方向に変えるか（ダンプ→削減、ラウンドトリップ→確定、負けポジションへの追加なし、手数料ハードル規律、アーム使用）。
何を学習しないのか？アルファ。2つのリコールチャンクをより良くランキングしても新しいトレードは見つからない。また、ゲート、サイジング、リスクレール、マンデートには一切触れない — これらはコードのままである。
なぜこれが利益への道なのか？測定された全損失の74%は、たった1つの行動クラス（2%未満の値動きでのフルブックダンプ、84クローズ中6件）から生じていた。デスクが既存のドクトリンを、それが適用される瞬間に確実に適用するようにすることは、測定された最大の漏出に対処する — さらに決定論的なLLMコストの利益（§6）も得られる。

2. 今日のプロンプト — 分散が存在する部分と存在しない部分

現在のプロンプト構成 ― 学習ループが変化させられるのは、原則テキスト全体の約3%(リコールライン)のみ。48,000文字のスキルウォールは構造的に分散0。

深層分析の発見1: 構築中のループは最小のチャネル上で学習する。発見2: 「Phase 1」はdesk_memoryコーパスとして出荷された — スキルウォールの設計されたアトミゼーションは実施されなかったため、デスクが読む内容の97%は依然として決して変化しない。

3. 学習ループの全体的な仕組み — エンドツーエンド

学習ループの全体フロー — 状況 → 検索（+探索、傾向スコアの記録） → ブリーフ → 判断 → ジャーナル → 結果の結合 → 行動代理指標 → シャドースコア（下方修正のみ） → 昇格ゲート → 重み付き検索。自動採掘された教訓は隔離を経て入場。

本日稼働中(コレクション) · 次のインクリメント(a3, b, c) · ゲート付きアクティベーション(d) · 破線 = 検疫済み/デフォルトオフ

4. 報酬が行動であってP&Lでない理由 — 識別可能性の数学

報酬がP&Lではなく行動である理由 — チャンク別の生のP&L帰属は現在の量では統計的に識別不可能(数年)。行動代理指標は数週間で判定可能。P&Lは昇格ゲートでポートフォリオ単位のみ。

6. ターゲット — 「プラスの利益」が実際にどこから来るのか

目標 — プラスの利益の実際の出所。確定的な利益(コスト)から、行動の改善、そして正直に言えば:アルファは約束しない。

出所性質仕組み
LLMプロンプトコスト確定的スキルの壁は、決定プロンプト1回あたり~12kトークンで、毎サイクル、毎ラン、永久に続く。状況別トップK(フェーズ4 / ステップe)はこれを60–80%削減する — 保証された、複利的なコスト削減。定義上のNET P&L。
キャパシティの余裕確定的ブロックキャップは4倍に引き上げられ、かつて6文字分の余裕しかなかった時期がある。#287は、そのキャップが密かに教訓のコストとなっていたことを示した。検索はこの繰り返しの負担を終わらせる。
損失形状の削減測定された行動測定された損失の74%が、単一の行動クラスに集中していた。その行動を実証的に変化させる教訓(link 1)は、帳簿上最大の漏れ — デーモンの本来の仕事 — に対処する。
検索アルファ主張しない2件のリコールチャンクをより良くランク付けしても、新たなアルファが生まれる可能性は低い。プロモーションゲートがコスト+損失形状の削減を超えるプラスのP&Lを測定することがあれば、それはアップサイドであり、計画ではない。

7. 自律性の境界 — 「自ら学ぶ」がここで意味すること

自律性の境界 — (f)以降、システムは自ら教訓を書き、測定された結果で重み付けし、証拠によって退役させる。ただし、確信ゲート・サイジング・レール・マンデートはデーモンが触れられないコードのままである。

システムが自ら行うことシステムが決して行わないこと
自身のクローズドランから候補となる教訓を書く (f)測定されたスコアなしに、自身の教訓を検疫状態から昇格させる
その結果が反証する教訓の重みを下げる (c)意見に基づいて重みを上げる — 重みは証拠にのみ基づく
各状況がどの検証済みの教訓を読むかを選択する (d/e)確信ゲート、サイジング、適応ラダー、エクイティレール、またはマンデートに触れる
クローズしたラン(a3/f)に応じて取得可能プールを拡張する決定論的な動作に戻すためのワンフラグ・キルスイッチなしで実行する

プラットフォームがすでに信頼している同じエンベロープです：単調に収束し、フラグでゲート制御され、ジャーナルを優先し、NET実現損益に基づいて昇格するか、まったく昇格しないかのいずれかです。
