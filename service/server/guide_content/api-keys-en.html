§2Set but limited — needs a decision

KeyIssueOptions
ALPHA_VANTAGE_API_KEY Free tier: 25 requests/day. News sentiment (4 categories) needs ~96/day at hourly. Set to a 6-hour cadence (MARKET_NEWS_REFRESH_INTERVAL=21600, ~16/day) so it fits — news sentiment works, but refreshes every 6h. Upgrade to premium (~$50/mo, alphavantage.co/premium) to restore hourly and lift the daily cap; then set MARKET_NEWS_REFRESH_INTERVAL=3600. Or leave it — 6h is fine for a slow sentiment signal.

§4The two you might act on

Alpha Vantage premium (hourly news)

alphavantage.co/premium — the $49.99/mo tier lifts the 25/day cap and the per-second burst limit. Paste the new key into ALPHA_VANTAGE_API_KEY, set MARKET_NEWS_REFRESH_INTERVAL=3600, recreate the container.

Per-source sentiment (X, Reddit, Telegram, YouTube)

The mockup shows five sentiment sources; we have StockTwits (free) + news headlines (Alpha Vantage). The others each need their own key/collector: X API (paid ~$100/mo), Reddit API (free tier), Telegram (bot API, needs a channel scraper), YouTube (Data API, free quota). This is a build project, not just a key.
