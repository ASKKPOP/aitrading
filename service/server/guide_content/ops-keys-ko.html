소유자 전용. 이 페이지는 어떤 프로덕션 비밀이 구성되어 있고 각각이 무엇을 구동하는지 나열합니다. 비밀 값 자체는 절대 포함하지 않으며, 상태와 길이만 표시합니다. 접근은 서버 측 이메일 허용 목록으로 제한됩니다.

§1설정됨 및 작동 중

9개의 키가 구성되어 프로덕션에서 작동 중입니다.

§2설정되었으나 제한됨 — 결정 필요

키문제옵션
ALPHA_VANTAGE_API_KEY 무료 등급: 하루 25회 요청. 뉴스 감성 분석 (4개 카테고리)은 시간당 기준 하루 약 96회가 필요합니다. 6시간 주기로 설정하여 (MARKET_NEWS_REFRESH_INTERVAL=21600, 하루 약 16회) 맞췄습니다 — 뉴스 감성 분석은 작동하지만 6시간마다 갱신됩니다. 프리미엄으로 업그레이드하면 (월 약 $50, alphavantage.co/premium) 시간당 갱신을 복원하고 일일 한도를 해제할 수 있습니다; 그런 다음 MARKET_NEWS_REFRESH_INTERVAL=3600로 설정하세요. 또는 그대로 두세요 — 느린 감성 신호에는 6시간도 괜찮습니다.

§3의도적으로 비워둠 — 오늘은 필요 없음

키비어 있어도 괜찮은 이유
OPENAI_API_KEY, GEMINI_API_KEY, XAI_API_KEY, DASHSCOPE_API_KEY, GLM_API_KEY, OPENROUTER_API_KEY저희는 Anthropic (Sonnet + Opus)을 기반으로 운영합니다. 이들은 계층화 시스템이 사용할 수 있지만 필요하지는 않은 대체 LLM 제공업체입니다.
ALPACA_KEY/SECRET, BINANCE_KEY/SECRET실제 주문 실행은 존재하지 않습니다 — Sooppiy는 설계상 페이퍼/시뮬레이터 플랫폼입니다.
RESEND_API_KEY이메일은 Resend가 아닌 SendGrid를 통해 전송됩니다.
LOCAL_LLM_API_KEY자체 호스팅 모델용입니다; 저희는 호스팅된 Anthropic API를 사용합니다.
프로덕션에서 키 편집하기. 키는 오직 ~/sooppiy/app/.env에만 존재합니다. 변경 후에는 컨테이너를 다시 생성해야 합니다 — --env-file 는 다음 위치에서만 읽습니다: docker run, 재시작 시에는 읽지 않습니다.

§4조치가 필요할 수 있는 두 가지

Alpha Vantage 프리미엄 (시간별 뉴스)

alphavantage.co/premium — 월 $49.99 요금제는 하루 25건 제한과 초당 버스트 제한을 해제합니다. 새 키를 ALPHA_VANTAGE_API_KEY에 붙여넣고 MARKET_NEWS_REFRESH_INTERVAL=3600을(를) 설정한 뒤 컨테이너를 다시 생성하세요.

소스별 감성 분석 (X, Reddit, Telegram, YouTube)

목업에는 다섯 개의 감성 소스가 표시되어 있지만, 우리는 StockTwits (무료) + 뉴스 헤드라인 (Alpha Vantage)만 보유하고 있습니다. 나머지는 각각 별도의 키/수집기가 필요합니다: X API (유료, 월 약 $100), Reddit API (무료 등급), Telegram (봇 API, 채널 스크레이퍼 필요), YouTube (Data API, 무료 할당량). 이것은 단순한 키 설정이 아니라 구축 프로젝트입니다.
