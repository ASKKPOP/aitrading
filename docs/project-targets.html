Project targets · architecture · status

An AI trading platform:
analyze, decide, simulate — automatically.

Built on Sooppiy (agent-native signal & copy-trading). We add a multi-agent AI analyst desk and a user-configurable automation loop so a trader — in the US or Thailand — can have AI research the market, reach a decision, and paper-trade it on a schedule. No real money is moved. Sooppiy 기반 · 멀티 에이전트 AI 분석 + 사용자 설정 자동화 루프 · 실제 자금 이동 없음(페이퍼 트레이딩)

◎The three targets

They form one loop: configuration drives analysis, analysis drives simulation. · 설정 → 분석 → 시뮬레이션의 한 루프

Target 1 · built ✓

Simulation buy & sell

Paper-trade signals against live market prices (crypto via Hyperliquid, US stocks via Alpha Vantage, events via Polymarket). Positions, cash, and PnL are tracked — no broker, no real funds.

Target 2 · built ✓

Multi-agent analysis

Four AI analysts — News, Sentiment, Fundamentals/Macro, Technical — gather data and brief a Trader + Risk team that debates them into a decision + report.

Target 3 · built ✓

Automation by user config

A user sets symbols, AI provider, schedule, confidence threshold, size and account. A background worker runs the analysis on that schedule and auto paper-trades when the decision meets the rules — simulator account only.
