เอกสารอ้างอิง API Keys

2026-07-17 · สถานะการใช้งานจริง · มองเห็นได้เฉพาะเจ้าของ org เท่านั้น · ค่าลับจริงจะไม่ถูกแสดงที่นี่
สำหรับเจ้าของระบบเท่านั้นหน้านี้แสดงรายการว่ามีการตั้งค่าความลับใดบ้างในระบบใช้งานจริง และแต่ละรายการใช้ทำอะไร โดยจะไม่แสดงค่าความลับจริง — มีเพียงสถานะและความยาวเท่านั้น การเข้าถึงถูกจำกัดด้วยรายชื่ออีเมลที่อนุญาตในฝั่งเซิร์ฟเวอร์

§1ตั้งค่าแล้วและใช้งานได้

ตั้งค่าและใช้งานจริงแล้วเก้าคีย์

คีย์หน้าที่การทำงานแหล่งที่มา
ANTHROPIC_API_KEYAI ทั้งหมด — บทวิเคราะห์นักวิเคราะห์, การตัดสินใจของเทรดเดอร์, การรวมข้อมูล, การตรวจสอบconsole.anthropic.com
EXECUTION_ENCRYPTION_KEYการเข้ารหัส AES-GCM สำหรับข้อมูลรับรองโบรกเกอร์ที่จัดเก็บไว้สร้างขึ้นเมื่อ 2026-07-17 ด้วยแอปของตัวเอง generate_key_b64
SENDGRID_API_KEYการแจ้งเตือนทางอีเมล (การจับคู่คำสั่งซื้อขาย, SL/TP, breaker, whale, รายการเฝ้าดู)sendgrid.com
TWILIO_ACCOUNT_SID · TWILIO_AUTH_TOKENการแจ้งเตือนทาง SMStwilio.com
SOSOVALUE_API_KEYกระแสเงินเข้า-ออกจริงของ ETF BTC/ETHsosovalue.com
COINMARKETCAL_API_KEYปฏิทินกิจกรรมคริปโตcoinmarketcal.com/en/api
ETHERSCAN_API_KEYการโอนของ ETH whale (เข้า/ออกจากตลาดแลกเปลี่ยน)etherscan.io/apis (ฟรี)
GOOGLE_CLIENT_SECRETการเข้าสู่ระบบผ่าน Google OAuthคอนโซล Google Cloud
ADMIN_TOKENการยืนยันตัวตนสำหรับเว็บไซต์ผู้ดูแล/ผู้จัดการตั้งค่าตอน deploy

§2ตั้งค่าแล้วแต่มีข้อจำกัด — ต้องมีการตัดสินใจ

คีย์ปัญหาตัวเลือก
ALPHA_VANTAGE_API_KEY แพ็กเกจฟรี: 25 requests/dayการวิเคราะห์ความรู้สึกจากข่าว (4 หมวดหมู่) ต้องการประมาณ 96/day หากทำทุกชั่วโมง จึงตั้งเป็นทุก 6 ชั่วโมง (MARKET_NEWS_REFRESH_INTERVAL=21600, ประมาณ 16/day) เพื่อให้พอดี — การวิเคราะห์ความรู้สึกจากข่าวยังทำงานได้ แต่รีเฟรชทุก 6 ชั่วโมง อัปเกรดเป็นแบบพรีเมียม (ประมาณ $50/mo, alphavantage.co/premium) เพื่อให้กลับมาทำงานทุกชั่วโมงและยกเลิกขีดจำกัดรายวัน จากนั้นตั้งค่า MARKET_NEWS_REFRESH_INTERVAL=3600 หรือปล่อยไว้แบบนี้ก็ได้ — 6 ชั่วโมงก็เพียงพอสำหรับสัญญาณความรู้สึกแบบช้า

§3ว่างเปล่าโดยตั้งใจ — ยังไม่จำเป็นในตอนนี้

คีย์เหตุใดการเว้นว่างจึงไม่มีปัญหา
OPENAI_API_KEY, GEMINI_API_KEY, XAI_API_KEY, DASHSCOPE_API_KEY, GLM_API_KEY, OPENROUTER_API_KEYเราใช้งานบน Anthropic (Sonnet + Opus) ส่วนนี้คือผู้ให้บริการ LLM ทางเลือกอื่นที่ระบบ tiering สามารถใช้ได้ แต่ไม่จำเป็นต้องใช้
ALPACA_KEY/SECRET, BINANCE_KEY/SECRETยังไม่มีการส่งคำสั่งซื้อขายจริง — Sooppiy ถูกออกแบบให้เป็นแพลตฟอร์มจำลอง/paper โดยเจตนา
RESEND_API_KEYอีเมลถูกส่งผ่าน SendGrid ไม่ใช่ Resend
LOCAL_LLM_API_KEYสำหรับโมเดลที่โฮสต์เอง เราใช้ Anthropic API แบบโฮสต์
การแก้ไข keys ในระบบใช้งานจริงKeys จะอยู่ใน ~/sooppiy/app/.env เท่านั้น หลังจากมีการเปลี่ยนแปลงใด ๆ คุณต้องสร้าง container ใหม่ — --env-file อ่านเท่านั้นที่ docker run, ไม่เคยตอนรีสตาร์ท

§4สองอย่างที่คุณอาจดำเนินการ

Alpha Vantage premium (ข่าวรายชั่วโมง)

alphavantage.co/premium — แพ็กเกจ $49.99/mo ยกเลิกขีดจำกัด 25/day และขีดจำกัดการเรียกแบบพุ่งต่อวินาที วางคีย์ใหม่ลงใน ALPHA_VANTAGE_API_KEY, ตั้งค่า MARKET_NEWS_REFRESH_INTERVAL=3600, สร้างคอนเทนเนอร์ใหม่

ความรู้สึกแยกตามแหล่งที่มา (X, Reddit, Telegram, YouTube)

ภาพจำลองแสดงแหล่งความรู้สึกห้าแหล่ง เรามี StockTwits (ฟรี) + หัวข้อข่าว (Alpha Vantage) ส่วนที่เหลือแต่ละแหล่งต้องมีคีย์/ตัวรวบรวมข้อมูลของตัวเอง: X API (แบบเสียเงินประมาณ $100/mo), Reddit API (ระดับฟรี), Telegram (bot API ต้องมีตัวดึงข้อมูลช่อง), YouTube (Data API โควตาฟรี) นี่คือโปรเจกต์ที่ต้องสร้างขึ้น ไม่ใช่แค่คีย์
