§2Diatur tetapi terbatas — perlu keputusan

KunciMasalahOpsi
ALPHA_VANTAGE_API_KEY Tingkat gratis: 25 permintaan/hari. Sentimen berita (4 kategori) memerlukan ~96/hari jika per jam. Diatur ke siklus 6 jam (MARKET_NEWS_REFRESH_INTERVAL=21600, ~16/hari) agar sesuai — sentimen berita berfungsi, tetapi diperbarui setiap 6 jam. Tingkatkan ke premium (~$50/bulan, alphavantage.co/premium) untuk mengembalikan siklus per jam dan menghapus batas harian; lalu atur MARKET_NEWS_REFRESH_INTERVAL=3600. Atau biarkan saja — 6 jam sudah cukup untuk sinyal sentimen yang lambat.

§3Sengaja dikosongkan — tidak diperlukan saat ini

KunciMengapa kosong tidak masalah
OPENAI_API_KEY, GEMINI_API_KEY, XAI_API_KEY, DASHSCOPE_API_KEY, GLM_API_KEY, OPENROUTER_API_KEYKami berjalan di Anthropic (Sonnet + Opus). Ini adalah penyedia LLM alternatif yang dapat digunakan oleh sistem tiering tetapi tidak diperlukan.
ALPACA_KEY/SECRET, BINANCE_KEY/SECRETTidak ada eksekusi order nyata — Sooppiy dirancang sebagai platform paper/simulator.
RESEND_API_KEYEmail dikirim melalui SendGrid, bukan Resend.
LOCAL_LLM_API_KEYUntuk model self-hosted; kami menggunakan API Anthropic yang di-hosting.
Mengedit kunci di produksi. Kunci hanya berada di ~/sooppiy/app/.env. Setelah perubahan apa pun, Anda harus membuat ulang container — --env-file hanya dibaca pada docker run, tidak pernah saat restart.

§4Dua hal yang mungkin perlu Anda tindak lanjuti

Alpha Vantage premium (berita per jam)

alphavantage.co/premium — paket $49.99/bulan menghapus batas 25/hari dan batas burst per detik. Tempel kunci baru ke ALPHA_VANTAGE_API_KEY, atur MARKET_NEWS_REFRESH_INTERVAL=3600, buat ulang container.

Sentimen per sumber (X, Reddit, Telegram, YouTube)

Mockup menampilkan lima sumber sentimen; kita memiliki StockTwits (gratis) + judul berita (Alpha Vantage). Sumber lainnya masing-masing memerlukan key/collector sendiri: X API (berbayar ~$100/bulan), Reddit API (tier gratis), Telegram (bot API, memerlukan channel scraper), YouTube (Data API, kuota gratis). Ini adalah proyek pembangunan, bukan sekadar key.
