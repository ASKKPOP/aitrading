Connect Webull to Sooppiy

Create a Webull OpenAPI App Key and App Secret, connect them on sooppiy.com/accounts, and point an automation rule at them. Written 2026-11-23 against production.

Status on sooppiy.com today: Webull is connectable on /accounts, and live routing is enabled (webull is on the production live allowlist). A live Webull order that opens or adds to a position is capped at $1,000: over the cap it is refused, never resized. Closing orders are not capped. Shorts are on (1x, US stocks only).

1. Before you start

  • An opened, verified Webull US brokerage account. Webull refuses the API application without one.
  • For shorts: a Webull margin account. A cash account cannot short.
  • Somewhere safe to hold the App Secret for a minute. Webull shows it once.
  • Two key pairs are separate: PaperTrade keys work only against Webull's sandbox, production keys only against the real market. Sooppiy picks the Webull host by the gateway's mode, so the key must match the mode.

2. PaperTrade keys (for shadow mode). Do this first.

Webull approves PaperTrade access automatically, usually within minutes. Start here and run shadow for a few days before going live.

  1. Log in at webull.com, click your avatar (upper right), then Developer Console.
  2. In the upper left of the Developer Console, click paperTrade, then Confirm Switch.
  3. Click API Keys in the left menu, then Apply for OpenAPI for PaperTrade.
  4. Click Register an API Application, give it a name (for example sooppiy-shadow), keep both permissions (Market Data and Trading), and Submit.
  5. Click Generate Key in the Operate column. Copy the App Key and App Secret from the pop-up now; you cannot view them again.
Optional: My Account (avatar menu, in paperTrade) lists your sandbox accounts (Individual Cash, Individual Margin, …). Reset on any card resets all sandbox accounts and gives every one a new Account ID, so re-enter the account id on Sooppiy afterwards if you set one.

3. Production keys (for live mode)

  1. In the Developer Console (switch back to live), open Access Credentials → API Keys and click Apply for API Service. Webull reviews it, usually in 1–2 business days.
  2. Once approved, click Register an API Application and fill the form.
    Untick “Enable 2FA Verification”. It is ticked by default. With it on, Webull requires an x-access-token that is created and approved in the Webull app, and Sooppiy does not send that token yet. Every request then fails with 401 and every order is refused. The trade-off: without 2FA, anyone holding the App Key and Secret can trade the account, so guard them like a password and reset the key if it leaks.
    Permissions: keep Market Data and Trading. There is no withdrawal permission to grant.
    Address segments (IP allowlist): optional. If you add one, it must include Sooppiy's server address 52.9.147.202, or Webull will reject Sooppiy's calls. Sooppiy may move hosting regions, so leaving it empty avoids a sudden break later.
  3. Click Generate Key and copy the App Key and App Secret from the pop-up.
  4. Later, Reset Key on this page issues a new pair and kills the old one at once. That is also your instant off-switch for Sooppiy.

4. Connect on sooppiy.com

  1. Go to sooppiy.com/accounts → Trading gateway. Set Region to US (this only orders the list) and Broker to webull.
  2. Paste the values:
    Webull calls itSooppiy field
    App KeyAPI key
    App SecretAPI secret
    Account ID (optional)Webull account id
    Account id: leave it empty if your Webull login has one account. With several accounts, Sooppiy will not guess, except that it picks the single cash account if there is exactly one. To trade shorts you must enter the margin account's id. This is the API account_id returned by Webull's account-list call, which is not necessarily the account number shown in the Webull app.
  3. Tick I accept the live-trading terms (required even for shadow), then Connect gateway. The gateway starts in paper, so nothing is sent to Webull yet.
  4. On the connected gateway's card, switch the mode to shadow (with PaperTrade keys) or live (with production keys). To go from shadow to live, delete the gateway and reconnect it with the production pair, then switch to live.

Sooppiy encrypts the keys at rest (AES-GCM) and never shows them again.

5. Point an automation rule at Webull

Connecting does not move any rule. A rule reaches Webull only when you set that rule's account type to shadow or live on the Automation page, and the rule trades US stocks. Crypto rules never go to Webull.

Watch the Broker orders and Drift records panels at the bottom of /accounts. They show what Webull confirmed next to what Sooppiy's ledger assumed, and differences are shown, never auto-corrected.

6. What Sooppiy sends to Webull

Sooppiy actionWebull orderNotes
buyBUYUS stocks and ETFs only, 1x, market DAY order, regular session
sellSELL
shortSHORT
coverBUY
  • Never sent: crypto, options, futures, leverage above 1x.
  • Covers are checked first. Webull has no buy-to-cover order, so a cover with no short behind it would open a long. Sooppiy reads your Webull positions and refuses a cover when nothing is held in that symbol or the cover is larger than the position.
  • $1,000 per opening order while Webull is new on the platform; closing orders are never capped.
  • Shorts follow the platform switch. If the operator re-arms long-only, short orders are refused; closing a position is never refused.
