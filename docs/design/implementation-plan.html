1리스크 엔진 — 손절 · 서킷브레이커 · 켈리✅ 완료 · 2026-07-14pytest 28케이스 · 실서버 E2E 검증

만드는 것

  • risk_engine.py — Kelly 사이징(f* = W−(1−W)/R, ½켈리 캡), 한도 체크, 브레이커 상태기계
  • DB: positions에 stop_loss·take_profit 컬럼, risk_limits·breaker_state 테이블
  • SL/TP 워처 루프(기존 가격 폴링에 편승, 30초) — 도달 시 페이퍼 자동 청산
  • automation.py 체결 직전에 게이트 삽입 (한 줄 훅)
  • API: GET/PUT /api/risk/limits · GET /api/risk/breaker · POST /api/risk/halt

완료 기준 (검수)

  • SL 걸린 포지션이 가격 도달 시 자동 청산되고 저널에 남는다
  • 일일 최대손실 초과 시 automation이 주문을 거부한다 (skip_reason)
  • HALT 발동 시 모든 자동매매 정지, 해제 전까지 유지
  • Kelly 계산이 저널의 승률·손익비 기반으로 사이즈를 낮춘다
  • pytest 케이스 ≥ 8

만드는 것

  • psych_feed.py — alternative.me F&G 수집(시간별) + 히스토리
  • 감성 Δ: 기존 뉴스 스냅샷 시계열에서 카테고리별 감성 변화율 → 스파이크 감지(z-score)
  • 충격 프록시: OKX 캔들 σ + 거래량비 결합, "추정" 라벨 필수
  • 기대감: Polymarket 배당률 스냅샷 저장 → Δ배당률
  • API: GET /api/market-intel/psych (F&G·spikes·anticipation 통합)

완료 기준

  • F&G 실측값이 대시보드/분석가에 반영 (오늘: 22 Extreme Fear)
  • 부정 감성 z>2 스파이크가 이벤트로 기록된다
  • 배당률 0.61→0.68류 변화가 Δ%로 조회된다
  • 4-분석가의 감성 분석가가 이 피드를 사용한다
