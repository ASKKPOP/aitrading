§2設定済みだが制限あり — 判断が必要

キー問題選択肢
ALPHA_VANTAGE_API_KEY 無料プラン：25リクエスト/日。 ニュースセンチメント（4カテゴリ）は1時間ごとだと約96/日必要です。6時間間隔（MARKET_NEWS_REFRESH_INTERVAL=21600、約16/日）に設定することで収まります — ニュースセンチメントは動作しますが、6時間ごとに更新されます。 プレミアムにアップグレード（約$50/月、alphavantage.co/premium）すると1時間間隔に戻せて日次上限も解除されます。その後 MARKET_NEWS_REFRESH_INTERVAL=3600 を設定してください。あるいはそのままでも構いません — 6時間でも緩やかなセンチメント信号としては十分です。

§3意図的に空 — 現時点では不要

キー空でも問題ない理由
OPENAI_API_KEY, GEMINI_API_KEY, XAI_API_KEY, DASHSCOPE_API_KEY, GLM_API_KEY, OPENROUTER_API_KEY私たちはAnthropic（Sonnet + Opus）で運用しています。これらはティアリングシステムが使用できる代替LLMプロバイダーですが、必須ではありません。
ALPACA_KEY/SECRET, BINANCE_KEY/SECRET実際の注文執行は存在しません — Sooppiyは設計上、ペーパー/シミュレーターのプラットフォームです。
RESEND_API_KEYメールはResendではなくSendGrid経由で送信されます。
LOCAL_LLM_API_KEYセルフホスト型モデル用です。私たちはホスト型のAnthropic APIを使用しています。
本番環境でのキー編集。 キーは ~/sooppiy/app/.env にのみ存在します。変更後は必ずコンテナを再作成する必要があります — --env-fileは起動時にのみ読み込まれ、docker run、再起動時には読み込まれません。

§4対応が必要な可能性がある2つ

Alpha Vantage プレミアム（1時間ごとのニュース）

alphavantage.co/premium — 月額$49.99のプランでは、1日25回の上限と秒間バーストの制限が解除されます。新しいキーを ALPHA_VANTAGE_API_KEY に貼り付け、MARKET_NEWS_REFRESH_INTERVAL=3600 を設定し、コンテナを再作成してください。

ソースごとのセンチメント（X、Reddit、Telegram、YouTube）

モックアップには5つのセンチメントソースが表示されていますが、現在利用可能なのは StockTwits（無料）とニュース見出し（Alpha Vantage）のみです。他のソースにはそれぞれ独自のキー／収集機構が必要です：X API（有料、月額約$100）、Reddit API（無料枠）、Telegram（ボットAPI、チャンネルスクレイパーが必要）、YouTube（Data API、無料クォータ）。これは単なるキー設定ではなく、構築プロジェクトです。
