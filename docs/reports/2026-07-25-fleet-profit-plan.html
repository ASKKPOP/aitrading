The plan — ranked by ROI

Three initiatives, in priority order. #1 is the foundation; without it, #2 and #3 are polishing a gamble. Each lists the concrete build steps, effort, and the bar that says it worked.

1

Edge measurement — Backtest & forward-eval harness

Impact: Highest Effort: High (~2–3 wks) Owner: backend/quant Greenfield: backtest.py

Why: No strategy is validated before it trades. The AI's confidence pins at 0.58–0.62 (barely above a coin flip), and −$138 from a signal that was right early / wrong late is noise, not a losing thesis. You're discovering expectancy live, with capital.

  • ABacktest engine — service/server/backtest.py, exposed via routes_research.py, historical bars from price_fetcher. Replay a strategy's decision logic over N months → equity curve, win-rate, Sharpe, max drawdown, expectancy per trade.
  • BNet-of-cost model — apply the live 0.1% taker fee + slippage so backtest P&L is what you'd actually keep (the −$19.47 fee floor was the whole realized loss here).
  • CPaper-forward eval — run a candidate strategy in shadow (no capital) for K days; log decision-vs-realized; compute live expectancy and compare to backtest.
  • DExpectancy gate — a fleet/run may only deploy capital if its strategy cleared a positive-expectancy bar (expectancy > round-trip fee, Sharpe > threshold) in both backtest and forward eval.
Done when: every fleet launch carries a backtest scorecard, and no negative-expectancy strategy can trade. Turns "deploy and hope" → "deploy what's proven."
2

Kill directional concentration

Impact: High Effort: Low–Med (~2–4 days) Quickest high-impact win Extends select_targets

Why: 4-of-4 crypto shorts is one correlated bet, not four. When crypto rallied together, nothing offset it — the direct cause of −$139. The per-market directional-balance guard doesn't stop an all-one-market, all-one-direction fleet.

  • AFleet-level caps in composition (symbol_research.select_targets / fleet_planner): max same-direction fraction across the whole fleet (e.g. ≤60%) and max single-market fraction (e.g. ≤50%).
  • BPrefer a long/short mix and cross-market spread when the batch allows, so the sleeve earns from being right relative, not from the whole tape going your way.
  • CSurface net exposure — show net long/short and per-market concentration in the fleet status strip, and bound it.
Done when: no fleet is >X% one direction or one market; net exposure is visible and capped. Removes the single-bet failure mode that sank this run.
3

Decisive AI reads — conviction v2

Impact: Medium Effort: Med (~1 wk, partly built) Pays off after #1

Why: Confidence is quantized and pins at 0.62 — the model can't separate strong setups from weak ones, so sizing and gating run on noise. More gates won't help; a sharper signal will.

  • APromote conviction-v2 — the component-score conviction is already computed shadow; make it the sizing + gating input (RUN_CONF_V2) and retire the scalar gate.
  • BCalibrate to realized win-rate — using #1's backtest data, map conviction → historical win-rate so position size scales with measured edge, not a flat fraction.
Done when: conviction correlates with realized win-rate and size scales with it. Note: this only pays off after #1 provides the calibration data — hence rank 3.
✓

Full-analysis cycles — human factors in every decision

✅ Shipped this session
Config: FLEET_CYCLE_MODE=full Cost: ~6 LLM calls/cycle

Found & fixed: the fleet picked symbols with the full factor stack (crypto weights: technical 30% · psych 20% · social 15% · news 15% — the "human fact"), but each 45-min trade decision ran in light mode: one LLM call on price + a frozen thesis, with analysts: {} empty. So it entered with human factors but managed the position blind to them — a direct reason it held every losing short into the rally.

  • ✓Flipped prod to FLEET_CYCLE_MODE=full — every cycle now re-runs News, Sentiment (psych / Fear&Greed / social), Fundamentals+macro (Polymarket/FRED) and Technical, then the Trader+Risk debate. Verified: all four analyst briefs populate.
  • →Next: because the per-cycle read now sees live sentiment, a regime turn can flip a stale "hold" — pairs with #1's calibration to make conviction mean something.
Live now: the next fleet you compose reads the full human-factor stack on every decision, not just at pick time. (Repo default stays light for cost; prod is full.)
