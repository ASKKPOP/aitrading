7 · Findings

CRITICAL F1 — Confidence output is quantized; the 0.65 gate decides trades on noise (RUN AI reading algorithm — change required)

96 decisions produced only 8 distinct confidence values; 51/96 (53%) are exactly 0.62, just under the 0.65 fleet gate. Consequences observed live:

• Run 34's winning ZEC short was called from cycle 1 @ 0.62 and blocked for ~12 h until a 0.65 roll — profit was luck of the roll, not gate quality.
• Run 38 re-ran the identical short 13× — blocked 13/13 while price fell 520.65 → 511.34 (≈ +$47 foregone at run-34 sizing).
• Run 37's blocked 0.62 buys sat at 1923–1928; the 0.65 entries that passed executed at 1947.5/1943.0 — the gate delayed the same thesis to a ~1% worse price.
• 3× narration/number mismatch: report text says "68% confidence" while the field says 0.62 — the scalar isn't calibrated to the model's own stated conviction.
• Fairness: the gate also blocked would-be losers (CAT short @ 881.64 → 901; BTC buys @ 65636–66009 dipped first). The problem is not "gate loses money" — it's that pass/block is uncorrelated with outcome.

Fix: recalibrate the decision-confidence output (wider dynamic range, outcome-calibrated), or gate on thesis-alignment instead of the raw scalar. Short-term mitigation: set fleet min_confidence ≤ 0.60 or derive it as thesis_confidence − margin.

CRITICAL F2 — US-stock runs have no technical data (Alpha Vantage premium wall)

Run 27 (TSLA) cyc 14–15 reports state: "The technical analyst has no verified price/volume data (Alpha Vantage premium wall, a recurring known gap)… any directional call would be guesswork." Worker logs confirm: [Macro Signal Error] premium endpoint every tick, [Market Intel] inserted=0 errors=6 every refresh.

Consequences: TSLA holds due to missing data, not market view — it will never trade in this state; CAT's chronically low 0.55–0.58 confidence likely shares the root; ~6 LLM calls/cycle are spent on runs structurally unable to act.

Fix: route us-stock technicals through the Yahoo feed already used for prices, or auto-pause runs whose data feed is dead (new paused_reason: data_unavailable).

WARNING F3 — Fleet builds runs whose thesis confidence is below the trade gate

Fleet 6 spawned ZC with thesis confidence 0.539 and CAT with 0.611, then set min_confidence 0.65 on both. A run weaker than its own gate is near-guaranteed to skip every cycle — it burns budget slots and LLM spend with no path to trading. The builder should reject sub-gate theses or set the gate relative to thesis confidence.

WARNING F4 — Spot runs receive bearish reads they cannot act on

Run 29 (BTC spot) produced sell decisions twice with no inventory → execute: no long position to sell. The futures short-mapping exists, but for spot runs a bearish read with an empty book is a wasted cycle. Either surface inventory to the prompt (so it holds instead of selling) or allow the fleet to pair spot theses with futures capability.
