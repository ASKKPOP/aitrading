6 · Findings

FIXED O1 — Frozen futures marks killed every true-futures run at ~18 min

The position price updater only refreshed crypto marks; other markets were priced once at entry and frozen. Stop evaluation fails closed on marks older than 900s → stop_eval_failed → fleet replaces → repeat. 9 runs churned (ZC, ZS×2, CL×6) before the fix; latent until the Plan 15 gate fixes let true-futures runs actually trade. Fix: refresh default crypto,futures,us-stock (commit 1dd1e57, image 20260723-markrefresh). 15 cycles / 0 churn events since — proven.

FIXED O2 — "100% lost" was the fee ledger, not P&L

Member cards rendered realized_pnl_usd, which is fees-only until a first close — every young run showed red even while winning (ZEC displayed −5.17 holding +$45). The member API now ships unrealized/total and the card renders the marked total (commit 6c31cf3, image 20260723-membertotals + SPA both hostnames). Verified live against fleet 9.

FIXED O3 — Kelly-sized dust orders

A $5.18 ZC add (fee half a cent) slipped past the budget floor because the Kelly cap sizes the final order. Dust guard now skips any sized order under max($10, 2% of max_bet) (commits 5200022 + b3501c5, images dustfloor + dustguard). The floor change itself was approved mid-window.

ALGORITHM O4 — The scalar re-pins; only computed conviction stays continuous

Yesterday's fix (calibration rubric) widened the scalar's range — for a while. Overnight it collapsed again onto a new attractor: 65% of 75 decisions emitted exactly 0.58 (6 distinct values all night). The component-computed conviction on the same decisions: 41 distinct values, properly ordered (winning CL cycles scored 0.61–0.65 while stale holds sat ~0.52). Conclusion: quantization is a property of asking an LLM for one number — no prompt fixes it. The gate must move to the computed conviction (P3 flip) once outcome data confirms; sizing already has.
