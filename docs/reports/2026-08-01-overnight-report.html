4 · Recommendations

권고 — 강한 순서대로

R-A · STRONG — exposure-feasibility gate at fleet build (the PR-#94 pattern).

The planner accepted a fleet whose minimum order ($25–34k) exceeded the $10k per-symbol cap — twice, because replacement build-parity re-creates the config after idle-retire. Two full churn laps burned ~24 LLM cycles each for zero trades. Exactly like the fee-infeasible class fixed by PR #94, the fix belongs at build time: refuse (or size down) any candidate whose minimum order can't pass the symbol-exposure cap. Deterministic, no trading-behavior change for valid fleets, testable (a $17k/5× candidate must be rejected/downsized; a $1.5k/1× candidate must pass). 플래너가 최소 주문이 상한을 넘는 플릿을 두 번 수용 — 수수료-불가능 클래스(PR #94)와 동일하게 빌드 시점 게이트로 거부/축소해야 함. 유효한 플릿엔 무영향, 테스트 가능.

R-B · Put a max_loss_usd on the five $1k cash runs (909–913) — they currently have no P&L stop; only notional bounds them. One-line setting each; I2 will keep any future value ≤$1,000. $1k 현물 런 5개에 max_loss 설정 권고 — 현재 P&L 스톱 없음.
R-C · Let the calibration scoreboard accumulate, then act on it. Step 0+1 are live; the first line already proves the thesis (raw 0.372 vs Platt 0.167, negative slope). After ~1–2 weeks of nightly lines: flip RUN_CONF_CALIBRATED=shadow, compare weekly Brier, then decide the gate change (Step 1 "apply") and the sub-score meta-model (Step 2) by measurement — the full plan is in 2026-08-01-confidence-calibration-solution.html. 보정 스코어보드 축적 후 측정으로 결정 — 첫 라인이 이미 논지를 입증(원시 0.372 대 Platt 0.167, 음의 기울기).
R-D · Keep I5/I2 armed and watch the firsts. The first conviction_collapse fire needs a correctness check (only on a held position, only after 2 real sub-0.35 reads); the first >$1,000 run request should show up as a clamp to exactly 1000.0.
