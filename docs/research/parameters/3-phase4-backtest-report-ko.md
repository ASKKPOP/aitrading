## 0. 요약

사전 등록 기준으로 평가한 결과 **증거 불충분(INSUFFICIENT_EVIDENCE)** — 플립 패키지(실행 게이트 기본 활성화)는 배포하지 않습니다. 배포-충실 설정(≥4/6)은 6년 워크포워드에서 OOS 거래가 **38건**뿐(기준 400건)이고, 승률 36.8%의 Wilson 90% 하한(0.28)과 PF 부트스트랩 하한(0.64) 모두 기준 미달. 민감도 행(≥3)은 237건으로 늘지만 PF 하한 0.88로 여전히 1.0 미만 — 수익성이 통계적으로 입증되지 않음.

**긍정적 발견:** 리스크 스택은 리서치가 약속한 대로 작동 — 최악 자산 최대 낙폭 **2.6%**(B&H는 같은 구간 −38%~−47%), 청산의 53%가 트레일링 스톱(승자 태우기), 시스템이 예측이 아니라 손실 차단으로 자본을 보전함. 검증 패널 통계 렌즈의 예측(트레이드 수 부족)이 정확히 적중.

**다음 단계:** 모든 기능은 표시/자문/옵트인으로 이미 배포 가능 상태. 라이브 텔레메트리(컨플루언스 벡터, 팩터 스냅샷)가 축적되면 B4 포함 6조건 시스템을 라이브-포워드로 재평가. 임계값은 리서치로 돌아감 — 프로덕션이 아니라.

## 1. 사전 등록된 설정 (결과 확인 후 무변경)

- **기본 행:** 배포-충실 기본값(`confluence_min=4`, `volume_confirm_min=1.5`), 튜닝 없음 — 설계상 스누핑 0.
- **워크포워드 행:** 앵커드, 4개 폴드, 14일 퍼지, 6-설정 그리드(보고됨), 훈련 구간에서 풀링 PF(≥30 거래)로 튜닝 후 테스트 구간 동결.
- **민감도 행:** `confluence_min=3` 고정 (B4는 과거 데이터에서 null → 6개 중 5개 조건만 달성 가능; 따라서 백테스트의 라이브 게이트는 배포판보다 오히려 *엄격*함).
- **판정 기준:** 풀링 OOS 거래 ≥400건, 미달 시 INSUFFICIENT_EVIDENCE · 승률 Wilson 90% 하한 > 0.50 · PF 부트스트랩 90% 하한 > 1.0 · 최악 자산 최대 낙폭 ≤ 30%.
- **범위 정직성:** B4 전 구간 null; B3는 MA/RSI/거래량으로 저하; B5 = F&G 축만(2018+ 전체 아카이브, 하루 추가 지연); S5 null; 이벤트 = 이중 출처 검증된 2019–2025 캘린더. 자산: BTC/ETH 봉은 2019-01부터(400봉 워밍업 후 신호 ≈2020-02), SOL은 2020-04부터(신호 ≈2021-05). 수수료 0.1%/레그 + 슬리피지 0.05%; t 종가 신호는 t+1 시가 체결.

## 2. 결과

### 기본 행 (배포-충실 ≥4/6) — 4개 OOS 폴드 × 3개 자산 풀링

| 지표 | 값 | 기준 | 충족? |
|---|---|---|---|
| OOS 거래 수 | **38** | ≥ 400 | ❌ (증거 하한선) |
| 승률 | 36.8% (14/38) | Wilson90 하한 > 0.50 → 하한 = **0.276** | ❌ |
| 프로핏 팩터 | 1.13 | 부트스트랩90 하한 > 1.0 → 하한 = **0.644** | ❌ |
| 최악 자산 최대 낙폭 | **2.63%** | ≤ 30% | ✅ |

폴드별: F1 (2021-07→2022-12, 약세장): 19건, PF 1.82 · F2: 6건, PF 0.69 · F3: 7건, PF 6.53 · F4 (2025-07→2026-07, 약세장): 6건, PF 0.0.
청산 구성: trail_stop 20건 (53%) · stop_loss 15건 · time_stop 3건 — 리서치가 처방한 추세추종 프로파일(적은 승률로 이기되 승자를 태움: 평균 승자 ≫ 평균 패자가 37% 승률에서 PF를 1 위로 밀어올리는 구조).

### 민감도 행 (가용 5개 중 ≥3)

237건 · 승률 37.1% (Wilson 하한 0.332) · PF 1.15 (부트스트랩 하한 **0.884**) · 최악 낙폭 8.97%. 증거는 늘었지만 결론은 동일: 점추정 수익성일 뿐, 손익분기와 통계적으로 구별되지 않음.

### 워크포워드 (폴드별 튜닝, 6개 설정 — 스누핑 반영)

모든 폴드가 `confluence_min=3`으로 튜닝됨; 테스트 PF: F1 1.46, F2 1.82, F3 0.69, F4 0.79. 엣지는 국면 의존적이며 폴드를 넘어 지속되지 않음 — 리서치의 "발표된 엣지는 감쇠한다" 경고와 일치.

### 조건 상관관계 (통계 렌즈가 예측한 그대로)

B1↔B2 일간 일치도 **0.709** (둘 다 추세 지표), B1↔B3 0.52, B2↔B3 0.40. 6개 조건은 독립이 아니며, "독립적인 53% 엣지 중첩" 산술을 액면 그대로 적용할 수 없음.

### 실제로 작동한 것

F4 약세장 구간에서 전략은 자산당 약 1.1–1.7% 손실에 그친 반면 바이앤홀드는 **−21% (ETH), −38% (BTC), −47% (SOL)**. 최대 낙폭 2–9% vs B&H의 역사적 60%+ 낙폭. 노출일 비율 3–6%. **시스템의 검증된 가치는 국면 필터링과 청산 스택을 통한 자본 보전 — 정확히 리서치의 "엣지는 예측이 아니라 리스크 관리에서 나온다"는 주장 그대로입니다. 검증되지 않은 것은 단독 수익성입니다.**

## 3. 결정 (사전 등록 규칙에 따라)

1. **플립 없음.** `CONFLUENCE_GATE_ENABLED`, `REGIME_FILTER_ENABLED`, `VOL_SIZING_ENABLED`는 **기본 off** 유지. 프리셋/`min_confidence` 이관도 배포하지 않음. 계획서의 문장이 그대로 적용됩니다: *"기준 미달이면 컨플루언스 임계값은 프로덕션이 아니라 리서치로 돌아간다."*
2. **그래도 배포되는 것 (이미 머지됨, 실행 동작 변화 0):** 컨플루언스 표시 + 에이전트 API, 국면 자문 + 타일, 텔레메트리(결정별 컨플루언스 벡터, 팩터 스냅샷), 안전성 수정(브레이커 tripped_by/expires_at, SL/TP 완화 금지, first_opened_at, 리스크 방향 게이팅, put_risk_limits 복구), 수리된 백테스터 지표, 옵트인 에이전트별 청산 툴킷(트레일링/시간 손절 — 개별 에이전트가 켤 수 있음; 수익성 주장이 아니라 포지션 리스크 도구).
3. **재평가 경로:** 라이브-포워드. Phase-1 텔레메트리가 모든 결정과 함께 6조건 벡터 전체(B4 포함)를 축적; 팩터 스냅샷이 펀딩/OI/롱숏/StockTwits를 기록. 게이트 품질의 라이브 결정이 ≥400건 쌓이면(또는 미래 백테스트가 누락 조건을 포함할 수 있게 되면) 기준을 재실행. 보정 테이블(컨플루언스 수별 적중률, Wilson CI)은 텔레메트리에서 자동으로 만들어짐.
4. **임계값 작업은 리서치로 복귀:** 데이터가 남긴 흥미로운 미해결 질문 — 더 단순한 진입 신호 위에 *청산 스택만*(트레일 + 시간 손절 + 국면 거부권) 얹어도 가치가 유지되는가. ≥4/5 컨플루언스 진입 게이트는 너무 엄격해 3개 자산 합쳐 연 6회만 거래했음.

*투자 자문이 아닙니다. 시뮬레이터 플랫폼입니다. 역사적 엣지는 감쇠하며, 이 수치들은 문서화된 범위 한계 안에서의 단일 백테스트를 설명할 뿐입니다.*
