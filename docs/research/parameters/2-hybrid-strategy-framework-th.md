## 1. หลักการสำคัญที่งานวิจัยพิสูจน์แล้ว

ข้อเท็จจริงที่ผ่านการตรวจสอบสองข้อขับเคลื่อนการออกแบบทั้งหมด:

1. **รูปแบบกราฟให้ข้อมูลได้ แต่ไม่สามารถทำกำไรได้ด้วยตัวเอง** (Lo–Mamaysky–Wang 2000; Savin 2007) มันบอกคุณว่า *บางสิ่ง* กำลังเกิดขึ้น โดยมีความได้เปรียบเพียง 53–54% เป็นอย่างมาก — อย่าใช้มันเป็นตัวกระตุ้นแบบเดี่ยวเด็ดขาด
2. **จิตวิทยาเป็นตัวขับเคลื่อนตลาด แต่สามารถนำมาใช้เทรดได้เฉพาะในช่วงสุดขั้วและในเวลาที่เฉพาะเจาะจงเท่านั้น** (sentiment ข้ามคืน ~6bp/SD; ความแม่นยำของ sentiment 50–55%; ความตื่นตระหนก/ความคลั่งไคล้คือจุดที่ผลกระทบเชิงพฤติกรรมกระจุกตัว)

ดังนั้นส่วนผสมคือ: **จิตวิทยาเป็นตัวกำหนด REGIME (เมื่อไหร่ และความเสี่ยงมากน้อยเพียงใด); กราฟเป็นตัวกำหนด TRIGGER (อะไร และที่ราคาเท่าไหร่); volume + sentiment เป็นตัวยืนยัน; volatility เป็นตัวกำหนด SIZE**

สัญญาณเป็นแบบสะสม ไม่ใช่แบบเด็ดขาด: แต่ละเงื่อนไขที่เป็นจริงจะเพิ่มคะแนนหนึ่งจุด; คุณจะลงมือทำก็ต่อเมื่อมีความสอดคล้องกัน (4+ จาก 6) เพราะสัญญาณที่แม่นยำ 53% เมื่อนำมาซ้อนกับสัญญาณอิสระอีกตัวที่แม่นยำ 53% คือวิธีที่ระบบจริงจะสามารถผ่าน 55% ได้

## 2. โครงสร้างการตัดสินใจสี่ชั้น

### ชั้นที่ 1 — ตัวกรอง regime ทางจิตวิทยา (จิตวิทยามนุษย์ = การกำหนด regime) — *"ควรเทรดหรือไม่ และควรใช้โหมดใด?"*
| อินพุต | สถานะ | โหมด |
|---|---|---|
| VIX / ระดับความกลัว | < 20 สงบ | **Trend mode** — ทำตามกราฟ |
| | 20–30 กังวล | ลดขนาด 50%, ตั้ง stop ให้แน่นขึ้น |
| | > 30 ตื่นตระหนก | **Contrarian mode** — เพิกเฉยต่อรูปแบบกราฟขาลง, เตรียมซื้อแบบ mean-reversion |
| ปฏิทินเหตุการณ์ (FOMC, CPI, การเลือกตั้ง) | ภายใน ±1 วัน | **ห้ามเปิดสถานะใหม่**; ถือหรือป้องกันความเสี่ยง |
| หัวข้อข่าวช็อกด้านสงคราม/นโยบาย | 1–3 วันแรก | ห้ามซื้อการดีดตัวครั้งแรกเด็ดขาด; รอสัญญาณการทรงตัว |
| โทนของ sentiment จากโซเชียล/ข่าว | คลั่งไคล้สุดขั้ว | เปิด contrarian sell-alert |
| | หวาดกลัวสุดขั้ว | เปิด contrarian buy-alert |

### ชั้นที่ 2 — เครื่องมือกำหนดทิศทาง (กราฟ: WHAT) — ตัวชี้วัดที่แข็งแกร่งที่สุดที่ได้รับการยืนยันแล้ว
- โมเมนตัม 12 เดือน (ข้ามเดือนล่าสุด) เป็นบวก → เอนเอียงไปทาง long / เป็นลบ → เอนเอียงไปทาง short
- ราคาเทียบกับ MA 200 วัน (สถานะ golden-cross) → ทิศทางเทรนด์
- การกลับตัวระยะสั้น 1 เดือน → จังหวะ counter-trend ภายใน bias

### ชั้นที่ 3 — Trigger และการยืนยัน (กราฟ + จิตวิทยารวมกัน: WHEN)
รูปแบบจะนับก็ต่อเมื่อ **สมบูรณ์ AND ได้รับการยืนยันด้วย volume AND sentiment ไม่ขัดแย้ง** เท่านั้น:
- สัญญาณขาขึ้น: การกลับตัวแบบ double-bottom / H&S-inverse **+ ปริมาณการซื้อขายเพิ่มขึ้น + ความรู้สึกข้ามคืนที่ไม่เป็นลบ**
- สัญญาณขาลง: double-top / H&S ที่สมบูรณ์ **+ ปริมาณการซื้อขายเพิ่มขึ้น + โทนข่าวที่แย่ลง**
- ไม่มีปริมาณการซื้อขาย = ไม่มีการเทรด (คุณลักษณะด้านปริมาณการซื้อขายได้รับการยืนยันว่าจำเป็น; Dinh & Kwon 2018)

### เลเยอร์ 4 — ขนาดและการออก (ความเสี่ยง: มากเท่าไร)
- ขนาดโพซิชัน = งบประมาณความเสี่ยง ÷ ความผันผวน (ยืนยันแล้ว: ความผันผวนเป็นตัวทำนายอันดับ 4 อันดับต้นและเป็นข้อมูลนำเข้าสำหรับการกำหนดขนาด)
- ตั้ง hard stop ไว้ใต้จุดที่รูปแบบถือเป็นโมฆะ; ใช้ trailing stop ด้วย MA
- Time stop: หากแนวคิดไม่เป็นไปตามที่คาดภายใน N วัน → ออก (ความแม่นยำของคุณอยู่ที่ประมาณ 55% ดังนั้นต้องตัดขาดทุนอย่างรวดเร็ว)

**กรณีพิเศษแบบสวนกระแส (panic buy):** VIX > 30 + ความรู้สึกอยู่ในภาวะกลัวสุดขีด + ราคาทรงตัวอยู่เหนือ MA ระยะสั้น + จุดสูงสุดของปริมาณการซื้อขายผ่านไปแล้ว → ซื้อแบบ mean-reversion ด้วยขนาดครึ่งหนึ่ง (นี่คือกรณี "ต้องโลภเมื่อคนอื่นกลัว" ที่ถูกทำให้เป็นระบบ)

## 6. การบริหารความคาดหวัง (ตัวเลขที่ผ่านการตรวจสอบ)

- ความแม่นยำเชิงทิศทางที่คาดหวังได้: **50–55%** ไม่ใช่ 80%
- ความได้เปรียบแบบ golden-cross: ประมาณ 4–5 จุดของอัตราชนะเหนือการโยนเหรียญ ก่อนหักต้นทุน
- ความได้เปรียบด้านความเชื่อมั่น: basis points ต่อวัน เป็นจริงเฉพาะในภาวะสุดโต่งและช่วงข้ามคืน
- ความได้เปรียบที่ทบต้นมาจาก: confluence (การซ้อนทับความได้เปรียบเล็กๆ ที่เป็นอิสระต่อกัน) การตัดขาดทุนอย่างรวดเร็ว การกำหนดขนาดสถานะตามความผันผวน และการข้ามช่วงเวลาเหตุการณ์สำคัญ — ไม่ใช่จากความสามารถในการทำนายที่เหนือชั้น
- ความได้เปรียบที่เผยแพร่ทุกอย่างจะเสื่อมลง ต้อง Backtest, paper-trade และตรวจสอบซ้ำแบบ out-of-sample ก่อนนำเงินจริงไปเสี่ยง
