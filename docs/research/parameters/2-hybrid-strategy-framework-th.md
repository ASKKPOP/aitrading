## 1. หลักการหลักที่งานวิจัยพิสูจน์ได้

ข้อเท็จจริงที่ผ่านการตรวจสอบสองข้อเป็นตัวขับเคลื่อนการออกแบบทั้งหมด:

1. **รูปแบบกราฟให้ข้อมูลได้แต่ไม่สามารถทำกำไรได้ด้วยตัวมันเองเพียงลำพัง** (Lo–Mamaysky–Wang 2000; Savin 2007) มันบอกคุณว่า *บางสิ่งบางอย่าง* กำลังเกิดขึ้น โดยมีความได้เปรียบสูงสุด 53–54% — อย่าใช้มันเป็นตัวกระตุ้นแบบเดี่ยว ๆ เด็ดขาด
2. **จิตวิทยาขับเคลื่อนตลาดได้ แต่สามารถนำมาซื้อขายได้เฉพาะในภาวะสุดขั้วและในช่วงเวลาเฉพาะเท่านั้น** (ความรู้สึกข้ามคืน ~6bp/SD; ความแม่นยำของความรู้สึก 50–55%; ความตื่นตระหนก/ความอิ่มเอิบใจคือจุดที่ผลกระทบเชิงพฤติกรรมรวมตัวกันหนาแน่น)

ดังนั้นส่วนผสมคือ: **จิตวิทยาเป็นตัวกำหนด REGIME (เมื่อไหร่ และความเสี่ยงมากน้อยแค่ไหน); กราฟเป็นตัวกำหนด TRIGGER (อะไร และที่ราคาเท่าไหร่); ปริมาณการซื้อขาย + ความรู้สึกตลาด CONFIRM (ยืนยัน); ความผันผวนเป็นตัวกำหนด SIZE (ขนาด)**

สัญญาณเป็นแบบสะสม ไม่ใช่แบบเด็ดขาด: แต่ละเงื่อนไขที่เป็นจริงจะเพิ่มคะแนน; คุณจะลงมือทำก็ต่อเมื่อมีความสอดคล้องกัน (4 จาก 6 ขึ้นไป) เพราะสัญญาณที่มีความแม่นยำ 53% เมื่อนำมาซ้อนกับสัญญาณอิสระที่แม่นยำ 53% อีกตัว จะทำให้ระบบจริงมีความแม่นยำเกิน 55% ได้

## 2. โครงสร้างการตัดสินใจสี่ชั้น

### LAYER 1 — ตัวกรองสภาวะจิตวิทยา (인간 심리 = 국면 판단) — *"ควรเทรดหรือไม่ และควรใช้โหมดไหน?"*
| ปัจจัยนำเข้า | สถานะ | โหมด |
|---|---|---|
| VIX / ระดับความกลัว | < 20 สงบ | **Trend mode** — ตามกราฟ |
| | 20–30 กังวล | ลดขนาด 50%, ตั้ง stop ให้แคบลง |
| | > 30 ตื่นตระหนก | **Contrarian mode** — เพิกเฉยต่อรูปแบบกราฟขาลง, เตรียมซื้อแบบ mean-reversion |
| ปฏิทินเหตุการณ์ (FOMC, CPI, การเลือกตั้ง) | ภายใน ±1 วัน | **ไม่เปิดสถานะใหม่**; ถือหรือป้องกันความเสี่ยง |
| ข่าวช็อกด้านสงคราม/นโยบาย | 1–3 วันแรก | ห้ามซื้อการดีดตัวครั้งแรกเด็ดขาด; รอสัญญาณการทรงตัว |
| น้ำเสียงความรู้สึกจากโซเชียล/ข่าว | ความอิ่มเอิบสุดขั้ว | เปิดสัญญาณเตือนขายแบบ Contrarian |
| | ความกลัวสุดขั้ว | เปิดสัญญาณเตือนซื้อแบบ Contrarian |

### LAYER 2 — เครื่องมือกำหนดทิศทาง (กราฟ: WHAT) — ตัวชี้วัดที่แม่นยำที่สุดที่ผ่านการยืนยันแล้ว
- โมเมนตัม 12 เดือน (ข้ามเดือนล่าสุด) เป็นบวก → เอนเอียงไปทาง long / เป็นลบ → เอนเอียงไปทาง short
- ราคาเทียบกับ MA 200 วัน (สถานะ golden-cross) → ทิศทางแนวโน้ม
- การกลับตัวระยะสั้น 1 เดือน → จังหวะสวนแนวโน้มภายในกรอบทิศทางหลัก

### LAYER 3 — สัญญาณกระตุ้นและการยืนยัน (กราฟ + จิตวิทยาร่วมกัน: WHEN)
รูปแบบจะนับได้ก็ต่อเมื่อ **สมบูรณ์ AND ได้รับการยืนยันด้วยปริมาณการซื้อขาย AND ความรู้สึกตลาดไม่ขัดแย้ง**:
- สัญญาณขาขึ้น: การทะลุแบบ double-bottom / H&S-inverse **+ ปริมาณการซื้อขายเพิ่มขึ้น + ความรู้สึกข้ามคืนที่ไม่เป็นลบ**
- สัญญาณขาลง: การเกิดรูปแบบ double-top / H&S สมบูรณ์ **+ ปริมาณการซื้อขายเพิ่มขึ้น + น้ำเสียงข่าวแย่ลง**
- No volume = no trade (volume features are verified essential; Dinh & Kwon 2018)

### เลเยอร์ 4 — ขนาดและการออก (ความเสี่ยง: HOW MUCH)
- ขนาดโพซิชัน = งบประมาณความเสี่ยง ÷ ความผันผวน (ยืนยันแล้ว: ความผันผวนเป็นตัวทำนายอันดับต้น 4 อันดับแรก และเป็นข้อมูลนำเข้าสำหรับการกำหนดขนาด)
- Hard stop ต่ำกว่าจุดที่รูปแบบเสียความถูกต้อง; trail ด้วย MA
- Time stop: หากสมมติฐานไม่เป็นไปตามคาดภายใน N วัน → ออก (ความแม่นยำของคุณอยู่ที่ประมาณ 55% ดังนั้นการขาดทุนต้องตัดให้เร็ว)

**กรณีพิเศษแบบสวนทาง (panic buy):** VIX > 30 + ความรู้สึกอยู่ในภาวะกลัวสุดขีด + ราคาทรงตัวเหนือ MA ระยะสั้น + จุดสูงสุดของปริมาณการซื้อขายผ่านไปแล้ว → ซื้อแบบ mean-reversion ด้วยขนาดครึ่งหนึ่ง (นี่คือกรณี "be greedy when others are fearful" ที่ถูกทำให้เป็นระบบ)

## 5. เมทริกซ์สถานการณ์ WHEN × WHAT

| สถานการณ์ (สภาวะจิตวิทยาตลาด) | ฝั่งที่มีอิทธิพลเหนือกว่า | การดำเนินการ |
|---|---|---|
| แนวโน้มขาขึ้นที่นิ่ง ความรู้สึกเชิงบวก | กราฟ | ตามเทรนด์: ซื้อเมื่อราคาย่อลงมาที่ MA พร้อมวอลุ่ม; ถือไว้ |

| ช่วง FOMC/CPI/การเลือกตั้ง | จิตวิทยา | หยุดนิ่ง/ไม่เปิดโพซิชันใหม่; กลับมาดำเนินการวันถัดไป |

## 6. การบริหารความคาดหวัง (ตัวเลขที่ผ่านการตรวจสอบแล้ว)

- ความแม่นยำเชิงทิศทางที่ควรคาดหวัง: **50–55%**, ไม่ใช่ 80%
- ประเภทความได้เปรียบแบบ golden-cross: ~4–5 จุดของอัตราชนะ เหนือกว่าการโยนเหรียญ ก่อนหักต้นทุน
- ความได้เปรียบจากความรู้สึก: basis points ต่อวัน เป็นจริงเฉพาะที่จุดสุดขั้วและช่วงข้ามคืนเท่านั้น
- ความได้เปรียบแบบทบต้นมาจาก: confluence (การซ้อนทับความได้เปรียบที่อ่อนแต่เป็นอิสระจากกัน), การตัดขาดทุนอย่างรวดเร็ว, การกำหนดขนาดโพซิชันตามความผันผวน, และการข้ามช่วงเหตุการณ์สำคัญ — ไม่ใช่มาจากความอัจฉริยะในการทำนาย
- ความได้เปรียบที่เผยแพร่ทุกอย่างจะเสื่อมลง ทำ Backtest, paper-trade และตรวจสอบซ้ำแบบ out-of-sample ก่อนนำเงินจริงไปเสี่ยง
