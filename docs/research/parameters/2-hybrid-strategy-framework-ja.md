## 1. リサーチが証明した核心原則

リサーチ全体の設計を導く、検証済みの2つの事実：

1. **チャートパターンは有益ではあるが、それ単体では利益を生まない**（Lo–Mamaysky–Wang 2000；Savin 2007）。何かが起きていることを示すものであり、優位性は良くても53–54%程度 ― 単独のトリガーとして使ってはいけません。
2. **心理は市場を動かすが、取引可能なのは極端な局面と特定のタイミングに限られる**（オーバーナイト・センチメント 約6bp/SD；センチメント精度 50〜55%；パニックや陶酔感の局面に行動的効果が集中する）。

つまり組み合わせはこうなる：**心理はレジーム（いつ、どれだけのリスクを取るか）を決め；チャートはトリガー（何を、どの価格で）を決め；出来高とセンチメントが確認を行い；ボラティリティがサイズを決める。**

シグナルは絶対値ではなく加算的なものである：満たされた条件ごとにポイントが加算され、コンフルエンス（6項目中4つ以上）がある場合にのみ行動する。なぜなら、独立した53%のシグナルを重ねることで、実際のシステムは55%を超えられるからだ。

## 2. 4層の意思決定スタック

### レイヤー1 — 心理レジーム・フィルター（人間心理＝レジーム判断）— *「そもそも取引すべきか、どのモードか？」*
| 入力 | 状態 | モード |
|---|---|---|
| VIX／恐怖レベル | 20未満 平穏 | **トレンドモード** — チャートに追随 |
| | 20〜30 神経質 | サイズを50%縮小し、ストップを厳格化 |
| | 30超 パニック | **逆張りモード** — 弱気のチャートパターンを無視し、平均回帰の買いを準備 |
| イベントカレンダー（FOMC、CPI、選挙） | ±1日以内 | **新規エントリーなし**；保有またはヘッジ |
| 戦争／政策ショックのヘッドライン | 最初の1〜3日 | 最初の反発は絶対に買わない；安定化シグナルを待つ |
| ソーシャル／ニュースのセンチメント傾向 | 極端な陶酔感 | 逆張り売りアラートON |
| | 極端な恐怖 | 逆張り買いアラートON |

### レイヤー2 — 方向性エンジン（チャート：WHAT）— 検証済みの最も強力な予測因子
- 12ヶ月モメンタム（直近1ヶ月を除く）がプラス → ロングバイアス／マイナス → ショートバイアス
- 200日移動平均に対する価格（ゴールデンクロス状態） → トレンド方向
- 1ヶ月短期リバーサル → バイアス内での逆張りタイミング

### レイヤー3 — トリガーと確認（チャート＋心理の組み合わせ：WHEN）
パターンは、**完成しており、かつ出来高で確認され、かつセンチメントが矛盾しない**場合にのみカウントされる：
- 強気トリガー: ダブルボトム / 逆H&Sブレイクアウト **+ 出来高増加 + 非負のオーバーナイトセンチメント**
- 弱気トリガー: ダブルトップ / H&S完成 **+ 出来高増加 + ニューストーンの悪化**
- 出来高なし = 取引なし（出来高特徴量は検証済みで必須; Dinh & Kwon 2018）

### レイヤー4 — サイズと出口（リスク: いくら）
- ポジションサイズ = リスク予算 ÷ ボラティリティ（検証済み: ボラティリティは上位4位の予測因子でありサイジング入力）
- パターン無効化ポイントの下にハードストップ; MAでトレール
- 時間ストップ: N日以内にシナリオが機能しない → 決済（あなたの的中率は約55%なので、負けは素早く切る必要がある）

## 5. WHEN × WHAT シナリオマトリクス

| シナリオ（市場心理の状態） | 優勢な側面 | アクション |
|---|---|---|
| 落ち着いた上昇トレンド、ポジティブなセンチメント | チャート | トレンドフォロー：出来高を伴う移動平均線への押し目買い；保有継続 |
| 落ち着いた下降トレンド | チャート | 見送り、または売り優勢；レイヤー1のパニックシグナルなしにナイフをキャッチしない |
| パニック（戦争の見出し、VIX >30、極度の恐怖） | 心理 | 1〜3日目：何もしない。その後、安定化トリガー（B5）で逆張り買い |
| 陶酔（放物線状の価格上昇＋誰もが強気） | 心理 | 強さの中で利益確定；売りトリガーはS4；決して追加しない |
| FOMC／CPI／選挙のウィンドウ | 心理 | 新規建玉なし／様子見；翌日再開 |
| 出来高を伴わないパターンのブレイクアウト | どちらでもない | 罠のリスク — 見送り（ほとんどの偽ブレイクアウトはここに存在する） |
| チャートは強気だが、実際のニュースでセンチメントが崩壊 | 心理が拒否権を発動 | 取引を見送る — ニュースレジームは古いチャートに勝る |
| センチメントにノイズあり、極端なし、チャートは明瞭 | チャート | チャートに従って取引；センチメントはタイブレーカーにすぎない |

## 6. 期待値管理（検証済みの数値）

- 期待すべき方向性の的中率：**50〜55%**、80%ではない。
- ゴールデンクロス型のエッジ：コストを差し引く前で、コイントスに対して勝率にして約4〜5ポイント。
- センチメントのエッジ：1日あたり数ベーシスポイント、極端な状況および夜間にのみ実効性がある。
- 複利的なエッジの源泉は：コンフルエンス（独立した弱いエッジの積み重ね）、負けをすばやく切ること、ボラティリティによるサイジング、イベントウィンドウを見送ることであり、予測の天才性からではない。
- 公開されたエッジはすべて減衰する。資金をリスクにさらす前に、バックテスト、ペーパートレード、そしてアウト・オブ・サンプルでの再検証を行うこと。
