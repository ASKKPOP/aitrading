## 1. 調査で実証された基本原則

全体の設計は2つの検証済み事実によって決まります：

1. **チャートパターンは情報価値があるものの、単独では収益を生みません**（Lo–Mamaysky–Wang 2000；Savin 2007）。何かが起きていることを示唆しますが、優位性はせいぜい53〜54%程度——単独のトリガーとして使ってはいけません。
2. **心理は市場を動かしますが、極端な状況や特定のタイミングでしか取引に活用できません**（オーバーナイトのセンチメントは約6bp/SD；センチメントの的中率は50〜55%；行動的効果はパニックや陶酔の局面に集中します）。

ですので組み合わせは以下の通りです：**心理学がREGIME（いつ、どれだけのリスクを取るか）を決定し、チャートがTRIGGER（何を、いくらで）を決定し、出来高＋センチメントがCONFIRMし、ボラティリティがSIZEを決定する。**

シグナルは絶対的ではなく加算的です：各条件が満たされるごとに1点が加算され、コンフルエンス（6項目中4項目以上）がある場合にのみ行動します。なぜなら、独立した53%のシグナルが積み重なることで、実際のシステムは55%を超えることができるからです。

## 2. 4層の意思決定スタック

### LAYER 1 — 心理レジームフィルター（인간 심리 = 국면 판단）— *「そもそもトレードすべきか、どのモードで行うか？」*
| 入力 | 状態 | モード |
|---|---|---|
| VIX / 恐怖レベル | < 20 平穏 | **トレンドモード** — チャートに従う |
| | 20–30 神経質 | サイズを50%削減、ストップをタイトに |
| | > 30 パニック | **逆張りモード** — 弱気のチャートパターンを無視し、平均回帰の買いを準備 |
| イベントカレンダー（FOMC、CPI、選挙） | ±1日以内 | **新規エントリーなし**；保有またはヘッジ |
| 戦争／政策ショックの見出し | 最初の1〜3日 | 最初の反発では絶対に買わない；安定化シグナルを待つ |
| SNS／ニュースセンチメントのトーン | 極度の熱狂 | 逆張り売りアラートON |
| | 極度の恐怖 | 逆張り買いアラートON |

### LAYER 2 — 方向エンジン（チャート：WHAT）— 検証済みの最強予測因子
- 12ヶ月モメンタム（直近1ヶ月を除く）がプラス → ロングバイアス／マイナス → ショートバイアス
- 価格と200日移動平均線の関係（ゴールデンクロス状態）→ トレンド方向
- 1ヶ月短期リバーサル → バイアス内での逆張りタイミング

### LAYER 3 — トリガー＆確認（チャート＋心理学の組み合わせ：WHEN）
パターンは**完成し、かつ出来高で確認され、かつセンチメントが矛盾しない**場合にのみカウントされます：
- 強気トリガー：ダブルボトム／逆H&Sのブレイクアウト **＋出来高増加＋オーバーナイトセンチメントが非ネガティブ**
- 弱気トリガー：ダブルトップ／H&Sの完成 **＋出来高増加＋ニュースのトーン悪化**
- 出来高なし＝取引なし（出来高特徴量は検証済みで必須；Dinh & Kwon 2018）

### レイヤー4 — サイズと決済（リスク：どれだけ）
- ポジションサイズ＝リスク予算 ÷ ボラティリティ（検証済み：ボラティリティは上位4予測因子の一つであり、サイジングの入力値）
- パターン無効化ポイントの下にハードストップを設定；MAでトレール
- タイムストップ：N日以内に想定が機能しない場合→決済（精度は約55%のため、損失は素早く切る必要がある）

## 5. WHEN × WHAT シナリオマトリクス

| シナリオ（市場心理状態） | 優勢な側 | アクション |
|---|---|---|
| 落ち着いた上昇トレンド、ポジティブなセンチメント | チャート | トレンドフォロー：出来高を伴う押し目でMAまで買い、保持 |
| 落ち着いた下降トレンド | チャート | 手を出さないかショートバイアス；Layer-1のパニックシグナルなしにナイフを掴まない |

| 陶酔（パラボリックな価格上昇＋皆が強気） | 心理 | 強さの中で利益確定；売りトリガーS4；決して追加しない |
| FOMC/CPI/選挙ウィンドウ | 心理 | フラット／新規エントリーなし；翌日再開 |

| チャートは強気だが、実際のニュースでセンチメントが崩壊 | 心理が拒否権を行使 | 取引をスキップ — ニュースレジームは古いチャートに勝る |
| センチメントはノイジーで極端なし、チャートは明確 | チャート | チャートを取引する；センチメントはタイブレーカーに過ぎない |

## 6. 期待値の管理（検証済みの数値）

- 期待すべき方向性の精度：**50〜55%**、80%ではない。
- ゴールデンクロス型のエッジ：コストを差し引く前で、コイントスに対して勝率にして約4〜5ポイント。
- センチメントエッジ：1日あたり数ベーシスポイント、極端な状況とオーバーナイトでのみ本物。
- 複利的なエッジの源泉：コンフルエンス（独立した弱いエッジの積み重ね）、負けをすばやく切ること、ボラティリティによるサイジング、イベントウィンドウのスキップ — 予測の天才性からではない。
- 発表されたすべてのエッジは劣化する。資金をリスクにさらす前に、バックテスト、ペーパートレード、そしてアウトオブサンプルでの再検証を行うこと。
