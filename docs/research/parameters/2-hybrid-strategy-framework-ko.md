# 하이브리드 프레임워크: 차트 패턴 × 인간 심리 융합
## The Hybrid Framework: Mixing Chart Patterns × Human Psychology

**2회의 검증된 딥 리서치(200+ 에이전트, 1차 출처 팩트체크)로 구축 · 2026년 7월**
**⚠️ 교육용 프레임워크이며 투자 자문이 아닙니다. 현실적 기대치: 방향 적중률 50–55% — 엣지는 단일 신호가 아니라 컨플루언스(중첩) + 리스크 관리에서 나옵니다.**

---

## 1. 리서치가 증명한 핵심 원리

전체 설계를 이끄는 검증된 사실 두 가지:

1. **차트 패턴은 정보가치는 있으나 단독으로는 수익성이 없습니다** (Lo–Mamaysky–Wang 2000; Savin 2007). *무언가* 일어나고 있다는 것은 알려주지만 엣지는 잘해야 53–54% — 절대 단독 트리거로 쓰지 마십시오.
2. **심리는 시장을 움직이지만 극단 구간과 특정 시점에서만 거래 가능합니다** (오버나이트 감성 ~6bp/SD; 감성 적중률 50–55%; 행동 효과는 패닉/유포리아에 집중됨).

따라서 조합은 이렇습니다: **심리가 국면(REGIME)을 정하고(언제, 리스크를 얼마나), 차트가 트리거(TRIGGER)를 정하고(무엇을, 어느 가격에), 거래량 + 감성이 확인(CONFIRM)하고, 변동성이 크기(SIZE)를 정합니다.**

신호는 절대적이 아니라 가산적입니다: 충족된 조건마다 1점을 더하고, 컨플루언스(6개 중 4개 이상)에서만 행동합니다 — 53% 신호를 독립적인 53% 신호들과 쌓는 것이 실제 시스템이 55%를 넘는 방법이기 때문입니다.

## 2. 4-레이어 의사결정 스택

### LAYER 1 — 심리 국면 필터 (인간 심리 = 국면 판단) — *"애초에 거래해야 하나, 어떤 모드로?"*
| 입력 | 상태 | 모드 |
|---|---|---|
| VIX / 공포 수준 | < 20 안정 | **추세 모드** — 차트를 따름 |
| | 20–30 불안 | 크기 50% 축소, 손절 타이트하게 |
| | > 30 패닉 | **역발상 모드** — 약세 차트 패턴 무시, 평균회귀 매수 준비 |
| 이벤트 캘린더 (FOMC, CPI, 선거) | ±1일 이내 | **신규 진입 금지**; 보유 또는 헤지 |
| 전쟁 / 정책 쇼크 헤드라인 | 첫 1–3일 | 첫 반등은 절대 사지 않음; 안정화 신호 대기 |
| 소셜/뉴스 감성 톤 | 극단적 유포리아 | 역발상 매도 경보 켜기 |
| | 극단적 공포 | 역발상 매수 경보 켜기 |

### LAYER 2 — 방향 엔진 (차트: WHAT) — 검증된 최강 예측 변수
- 12개월 모멘텀(최근 1개월 제외) 양(+) → 롱 편향 / 음(−) → 숏 편향
- 가격 vs 200일 이동평균 (골든크로스 상태) → 추세 방향
- 1개월 단기 반전 → 편향 안에서의 역추세 타이밍

### LAYER 3 — 트리거 & 확인 (차트 + 심리 함께: WHEN)
패턴은 **완성되고 AND 거래량이 확인되고 AND 감성이 모순되지 않을 때만** 유효합니다:
- 강세 트리거: 쌍바닥 / 역헤드앤숄더 돌파 **+ 거래량 증가 + 오버나이트 감성 비음(非陰)**
- 약세 트리거: 쌍봉 / 헤드앤숄더 완성 **+ 거래량 증가 + 뉴스 톤 악화**
- 거래량 없으면 거래 없음 (거래량 피처는 필수로 검증됨; Dinh & Kwon 2018)

### LAYER 4 — 크기 & 청산 (리스크: HOW MUCH)
- 포지션 크기 = 리스크 예산 ÷ 변동성 (검증: 변동성은 상위 4대 예측 변수이자 사이징 입력)
- 패턴 무효화 지점 아래 하드 손절; 이동평균으로 트레일링
- 시간 손절: N일 안에 논지가 작동하지 않으면 청산 (적중률이 ~55%이므로 지는 포지션은 빨리 잘라야 함)

## 3. 매수 체크리스트 (컨플루언스 6개 중 4개 이상 → 매수)

| # | 신호 | 출처 측 | 검증 근거 |
|---|---|---|---|
| B1 | 가격이 200일 이동평균 위 / 골든크로스 상태 | 차트 | Brock 1992: 매수신호일 연환산 +12% |
| B2 | 12-1 모멘텀 양(+) | 차트 | GKX 2020: ML 예측 변수 1위 |
| B3 | 강세 패턴이 거래량과 함께 완성 | 차트 | LMW 2000 정보가치 + 거래량 필수 |
| B4 | 오버나이트/뉴스 감성 긍정 또는 회복 중 | 심리 | Fed: 익일 ~6bp/SD |
| B5 | 공포 스파이크 소멸 중 (VIX가 30+ 고점에서 하락) | 심리 | 과잉반응/평균회귀 문헌 |
| B6 | 24시간 내 FOMC/CPI/주요 이벤트 없음 | 심리 | 이벤트 리스크 타이밍 |

**역발상 스페셜 (패닉 매수):** VIX > 30 + 감성 극단적 공포 + 가격이 단기 이동평균 위에서 안정화 + 거래량 클라이맥스 통과 → 절반 크기로 평균회귀 매수. ("남들이 두려워할 때 탐욕스러워라"를 시스템화한 케이스.)

## 4. 매도 체크리스트 (컨플루언스 6개 중 4개 이상 → 매도/회피)

| # | 신호 | 출처 측 |
|---|---|---|
| S1 | 가격이 200일 이동평균 아래 / 데드크로스 상태 | 차트 |
| S2 | 모멘텀이 음(−)으로 전환 | 차트 |
| S3 | 약세 패턴(쌍봉/헤드앤숄더)이 거래량과 함께 완성 | 차트 |
| S4 | 감성 유포리아 극단 (전원 강세, 밈주식 광풍 톤) | 심리 — 역발상 |
| S5 | 부정적 정책/지정학 쇼크 미해결 | 심리 |
| S6 | 손절 / 변동성 목표 도달 | 리스크 (항상 모든 것에 우선) |

## 5. WHEN × WHAT 시나리오 매트릭스

| 시나리오 (시장 심리 상태) | 지배 측 | 행동 |
|---|---|---|
| 안정적 상승 추세, 긍정 감성 | 차트 | 추세 추종: 거래량 동반 이동평균 눌림목 매수; 보유 |
| 안정적 하락 추세 | 차트 | 관망 또는 숏 편향; Layer-1 패닉 신호 없이 떨어지는 칼 잡지 않기 |
| 패닉 (전쟁 헤드라인, VIX >30, 공포 극단) | 심리 | 1–3일차: 아무것도 하지 않음. 이후 안정화 트리거(B5)에서 역발상 매수 |
| 유포리아 (포물선 가격 + 전원 강세) | 심리 | 강세 속 이익 실현; 매도 트리거 S4; 절대 추가 매수 없음 |
| FOMC/CPI/선거 윈도 | 심리 | 플랫/신규 진입 금지; 다음 날 재개 |
| 거래량 없는 패턴 돌파 | 어느 쪽도 아님 | 함정 위험 — 스킵 (가짜 돌파 대부분이 여기 삶) |
| 차트는 강세지만 실제 뉴스로 감성 붕괴 중 | 심리가 거부권 | 거래 스킵 — 뉴스 국면이 낡은 차트를 이김 |
| 감성 노이즈, 극단 없음, 차트는 명확 | 차트 | 차트대로 거래; 감성은 타이브레이커일 뿐 |

## 6. 기대치 관리 (검증된 수치)

- 기대할 방향 적중률: **50–55%**, 80%가 아님.
- 골든크로스류 엣지: 비용 차감 전, 동전 던지기 대비 승률 약 4–5%p.
- 감성 엣지: 하루 기준 베이시스포인트 수준이며, 극단 구간과 오버나이트에서만 실재.
- 복리 엣지의 원천: 컨플루언스(독립적인 약한 엣지 중첩), 지는 포지션 빠른 손절, 변동성 기반 사이징, 이벤트 윈도 회피 — 예측 천재성이 아님.
- 발표된 모든 엣지는 감쇠합니다. 실제 자금을 걸기 전에 백테스트, 페이퍼 트레이딩, 아웃오브샘플 재검증을 거치십시오.
