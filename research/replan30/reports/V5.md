The defects below are falsifier *mis-specification* and *confounding*, not absence.

**Cross-cutting defects (apply to multiple plans):**

1. **#592 confound on every ratchet-fee falsifier** (P1-2, P4-6, P5-5). "Next 20 fires median give-back <100%" is measured against the 102.9% all-time baseline, but #592 RATCHET_LOCK_FRAC (live since 08-27, 4/4 fires already <100%) alone can produce a pass. The falsifier cannot attribute success to the fee reprice. **Fix:** baseline = post-#592 fires only (47–73% observed), and the fee-fix's own metric = arm rate — fraction of trips whose peak exceeded 16bp that armed (currently: winners <0.2% never arm). That is the quantity the change moves.
2. **Simultaneous-ship attribution.** P4 ships actions 1, 4, 5, 6 in one week; P5 ships 2–5 in overlapping windows. Falsifiers that read shared metrics (platform P&L, payoff, "improve vs −$302/mo" in P4-1, "platform-ex-5 turns negative" in P5-2) cannot isolate which ship failed. P5 mostly uses per-mechanism metrics (correct); P4-1's falsifier is unrunnable as stated. **Fix:** every falsifier must read a mechanism-specific observable (stop-distance distribution, count of add-fills at negative uPnL, give-back, geometry-retire count), never the shared book P&L, except at the pre-registered program gate.
3. **Chandelier-replay censoring** (P1-5, feeds P4-3/P5-7 exit design). The 110-trip tape ends at each actual exit; a 2×ATR trail's counterfactual path *beyond* the actual exit is unobservable from fills. The experiment as stated cannot be computed. **Fix:** name the data source (continuous 60s mark history per symbol — prod mark cache or OKX candles, with the known feed-basis trap from the ratchet replay) or downgrade the claim.
4. **Replay optimism on stop fills.** All "payoff 0.27→1.49/2.11" numbers assume stopped trips exit exactly at the cap; measured slip is 6.8bp and the frozen-mark history says overrun is real. Post-ship falsifiers cover this, but the +$240–300/mo forecasts should carry a slip haircut now.
